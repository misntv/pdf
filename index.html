Gabung PDF

    Pecah PDF

    Ambil rentang halaman tertentu, atau pecah setiap halaman jadi berkas sendiri.

    SUSUN

    Hasil dibungkus satu arsip ZIP.

    03

    Ubah Info PDF

    Edit metadata: judul, penulis, subjek, kata kunci, pembuat, produser.

    SUSUN
    04

    Watermark

    Cap teks atau gambar — diagonal, tengah, atas, bawah, atau pola menyeluruh.

    SUSUN
    05

    Baca PDF

    Pratinjau cepat: navigasi halaman, zoom, rotasi. Tombol ← → aktif.

    LIHAT
    / – ZOOM
    06

    Thumbnail PDF

    Muat grid thumbnail halaman, lalu unduh sebagai arsip PNG.

    LIHAT
    07

    PDF → Word

    Teks PDF disalin ulang menjadi dokumen .docx yang bisa diedit.

    KONVERSI

    Konversi berbasis teks: hasil terbaik untuk dokumen teks; tampilan persis (font/gambar) tidak dijamin.

    08

    PDF → HTML

    Susun ulang PDF menjadi satu halaman web mandiri (inline, tanpa aset luar).

    KONVERSI
    09

    PDF → EXE

    Bungkus PDF menjadi peluncur Windows sekali-klik (self-extracting).

    KONVERSI

    Peramban tidak dapat mengompilasi biner .exe asli. Alat ini membuat peluncur Windows (.bat self-extracting): PDF ditanam base64 di dalamnya; saat diklik dua kali di Windows, file diekstrak & dibuka otomatis dengan pembaca PDF bawaan (via certutil, tersedia di semua Windows modern). Untuk .exe native sungguhan dibutuhkan kompiler desktop.

    10

    Ekstrak Teks & Gambar

    Panen teks dan gambar raster yang tertanam di dalam PDF.

    KONVERSI

    Gambar vektor murni tidak bisa diekstrak sebagai bitmap utuh; yang diambil adalah objek gambar raster tertanam.

    11

    Proteksi PDF

    Kunci PDF dengan kata sandi pengguna & izin terbatas.

    KEAMANAN

    Metode kompatibel-luas: halaman dirender ulang lalu dikunci (jsPDF RC4). Teks tetap terbaca mesin secara visual, namun dilindungi sandi & izin.

    12

    Buka Proteksi

    Lepaskan sandi PDF — Anda wajib tahu kata sandinya.

    KEAMANAN

    Hasil dibangun ulang dari render halaman (kualitas tinggi) tanpa sandi. Alat ini tidak membobol sandi yang tidak diketahui.

    13

    Magic PDF

    Tangkap layar / jendela / tab via share-screen, jadikan PDF, atau kirim ke printer Windows.

    MAGIC

    Pilih layar penuh, jendela aplikasi, atau tab. Snapshot dirangkai jadi PDF, atau langsung dikirim ke dialog cetak Windows (pilih printer fisik, atau “Microsoft Print to PDF”).
